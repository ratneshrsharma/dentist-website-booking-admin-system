# Backend Engineering Documentation

## Architecture
* **Framework:** PHP 8.2+ with Laravel MVC
* **Administration:** AdminLTE 4 cleanly integrated with Blade & REST API controllers
* **Security:** PSR-12, OWASP Top 10 hardening, input sanitization, CSRF tokens, strict session flags
* **Database:** MySQL 8.0+ / MariaDB with migrations, seeders, and indexed query optimizations

## Modules
* Auth & RBAC Engine (Super Admin, Clinic Manager, Doctor, Receptionist, Billing, Website Manager)
* CMS Pages & Blog Posts Manager
* Theme Customizer & Design Tokens Manager
* Yoast-Style SEO Suite & Script Injection
* Appointments, Calendar & EMR Odontogram
