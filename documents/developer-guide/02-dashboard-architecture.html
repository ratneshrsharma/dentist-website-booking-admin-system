1. Route, Controller & View Templates

Attribute Technical Specification
HTTP Route GET /admin/dashboard (or /admin)
Controller backend/app/StandaloneRunner.php::handleAdmin('dashboard') or DashboardController::index()
Blade Template backend/resources/views/admin/dashboard.blade.php extending layouts/admin.blade.php
RBAC Gate Accessible by all 6 roles (KPIs are filtered server-side based on role permissions).

2. Real-Time KPI Calculation Algorithms

The dashboard displays 4 core practice performance tiles:

KPI Card Default Value Calculation Logic / SQL Query
Today's Appointments 24 Patients SELECT COUNT(*) FROM appointments WHERE appointment_date = CURRENT_DATE() AND clinic_id = :clinic_id
Active Patients (EHR) 1,420 Patients SELECT COUNT(*) FROM patient_profiles WHERE is_active = 1
Low Stock Alerts 4 Items SELECT COUNT(*) FROM clinic_stocks cs JOIN inventory_items ii ON cs.inventory_item_id = ii.id WHERE cs.quantity <= ii.reorder_level
Today's Collections (POS) $4,850.00 SELECT COALESCE(SUM(amount_paid), 0) FROM invoices WHERE DATE(created_at) = CURRENT_DATE() AND payment_status = 'paid'

5. Support Tickets & Root Cause Analysis (RCA)

TICKET-DASH-201 • Collections card shows $0.00 while POS invoices exist
Data Discrepancy

Symptom: Billing officer logged payments, but Practice Dashboard displays "$0.00" on Today's Collections card.

Root Cause: Timezone mismatch between MySQL server (UTC) and Clinic local timezone (e.g. America/Chicago or Europe/London). Invoices created after 7:00 PM UTC roll into the next day under CURRENT_DATE().

Resolution Runbook:

  1. In config/app.php and config/database.php, ensure 'timezone' => 'America/Chicago' or clinic timezone is configured.
  2. Update SQL query to use timezone-aware date comparisons: DATE(CONVERT_TZ(created_at, '+00:00', :tz_offset)) = CURRENT_DATE().
TICKET-DASH-202 • Switching active branch does not refresh dashboard KPIs
Session State

Symptom: Doctor toggles clinic branch in top navbar dropdown, but appointment table continues showing Central Practice appointments.

Root Cause: The branch selector link was not passing ?clinic_id=2 or session variable was not updated before reloading the view.

Resolution Runbook:

  1. Inspect layouts/admin.blade.php branch selector: ensure link triggers /admin/dashboard?set_clinic={id}.
  2. Verify StandaloneRunner.php intercepts $_GET['set_clinic'] and commits it to $_SESSION['active_clinic_id'].
