Global Setting Standard Value Notes
Base URL https://demo.ratneshsharma.com/advanced-dental-clinic/api/v1 Prefix all requests with this root path.
Headers Required Accept: application/json
Content-Type: application/json
X-CSRF-TOKEN: {token}		 CSRF token required on all state-mutating requests (POST, PUT, DELETE).
Rate Limits • General APIs: 60 requests / minute

POST /api/v1/auth/login
Scope: Public

Authenticates staff credentials, establishes an HTTP-only secure session cookie, and returns user identity and bearer token.

Request Payload:

{
  "email": "dr.caldwell@example.com",
  "password": "Password123!",
  "remember": true
}

200 OK Response:

{
  "success": true,
  "message": "Staff authentication successful.",
  "token": "adc_token_5a8f9c2d1b...",
  "user": {
    "id": 3,
    "name": "Dr. Ethan Caldwell, DDS, FACP",
    "email": "dr.caldwell@example.com",
    "role": "doctor",
    "clinic_id": 1,
    "branch": "Central Practice (HQ)"
  }
}
POST /api/v1/auth/logout
Scope: Authenticated Staff

Terminates active staff session, destroys server-side session state, and revokes access token.

Headers Required:

Authorization: Bearer adc_token_...

200 OK Response:

{
  "success": true,
  "message": "Staff session successfully terminated and access token revoked."
}
