POST /api/v1/auth/login
Scope: Public

Authenticates staff credentials, establishes an HTTP-only session cookie, and returns user identity.

Request Payload:

{
  "email": "dr.caldwell@example.com",
  "password": "Password123!",
  "remember": true
}

200 OK Response:

{
  "success": true,
  "message": "Authentication successful.",
  "user": {
    "id": 3,
    "name": "Dr. Ethan Caldwell, DDS",
    "email": "dr.caldwell@example.com",
    "role": "doctor",
    "clinic_id": 1,
    "is_2fa_enabled": false
  }
}

GET /api/v1/appointments/slots
Scope: Public & Staff

Calendly-style availability engine querying doctor schedules and operatory chair capacities.

Query Parameters:

  • date (required, string, YYYY-MM-DD): Target booking date.
  • doctor_id (optional, integer): Clinician ID.
  • clinic_id (optional, integer): Branch location ID.

200 OK Response:

{
  "success": true,
  "date": "2026-11-15",
  "available_slots": [
    { "time": "09:00", "status": "available", "period": "morning" },
    { "time": "09:45", "status": "available", "period": "morning" },
    { "time": "10:30", "status": "booked", "period": "morning" },
    { "time": "14:00", "status": "available", "period": "afternoon" },
    { "time": "15:30", "status": "available", "period": "afternoon" }
  ]
}
POST /api/v1/appointments
Scope: Public & Staff (Rate limit: 10/min)

Dispatches appointment booking with pessimistic chair lock and WhatsApp triage notification.

Request Payload:

{
  "patient_name": "Eleanor Vance",
  "patient_phone": "+447911123456",
  "patient_email": "eleanor.vance@example.co.uk",
  "appointment_date": "2026-11-15",
  "appointment_time": "14:00",
  "doctor_id": 1,
  "clinic_id": 1,
  "treatment_type": "Dental Implants Consult",
  "notes": "Interested in Straumann BLX implant options."
}

201 Created Response:

{
  "success": true,
  "message": "Appointment booked successfully.",
  "booking_reference": "APT-2026-8942",
  "whatsapp_confirmation_url": "https://wa.me/919904379260?text=..."
}
POST /api/v1/emr/odontogram
Scope: Doctor & Admin

Saves 5-surface tooth condition or periodontal probing depth for patient odontogram chart.

Request Payload:

{
  "patient_id": 1042,
  "tooth_number": 19,
  "surface": "O",
  "condition": "caries",
  "pocket_depth": 3.5,
  "clinical_notes": "Early enamel breakdown on occlusal fissure."
}

200 OK Response:

{
  "success": true,
  "message": "Odontogram chart updated successfully.",
  "record_id": 8421
}
