2. 6-Role System Access Matrix

Role Code Role Title Permitted Scope Restricted Areas
super_admin Super Administrator Full system access across all 12 modules and all 3 clinic branches. None
admin Clinic Branch Admin Manage assigned branch, appointments, staff roster, supplies. System-wide RBAC editing
doctor Dental Clinician / Surgeon Odontogram EMR, patient health records, clinical scheduling. Billing POS, CMS, Theme, SEO
receptionist Appointment Coordinator Calendar scheduling, patient intake, WhatsApp dispatch. Odontogram, Invoices, Settings
website_manager Webmaster / Marketing Theme customizer, CMS pages, SEO metadata, 301 redirects. All Clinical EMR, Patients, Billing
billing Billing & Finance Officer Invoices, POS, digital receipts, insurance claims. Clinical Odontogram, CMS, System

3. Server-Side Session Guard (checkPermission)

public static function checkPermission(string $action, string $userRole): bool
{
    $matrix = [
        'super_admin'     => ['all'],
        'admin'           => ['dashboard', 'appointments', 'patients', 'clinics', 'inventory', 'billing'],
        'doctor'          => ['dashboard', 'appointments', 'emr', 'patients', 'inventory:view'],
        'receptionist'    => ['dashboard', 'appointments', 'patients:intake'],
        'website_manager' => ['dashboard', 'cms', 'theme', 'seo'],
        'billing'         => ['dashboard', 'billing', 'patients:billing', 'inventory:po'],
    ];

    if ($userRole === 'super_admin') return true;
    return in_array($action, $matrix[$userRole] ?? []);
}

4. Database Schema (users table)

CREATE TABLE `users` (
  `id` bigint unsigned NOT NULL AUTO_INCREMENT PRIMARY KEY,
  `name` varchar(255) NOT NULL,
  `email` varchar(255) NOT NULL UNIQUE,
  `password` varchar(255) NOT NULL,
  `role` enum('super_admin','admin','doctor','receptionist','website_manager','billing') NOT NULL DEFAULT 'receptionist',
  `clinic_id` bigint unsigned NULL,
  `is_2fa_enabled` tinyint(1) NOT NULL DEFAULT 0,
  `two_factor_secret` text NULL,
  `is_active` tinyint(1) NOT NULL DEFAULT 1,
  `last_login_at` timestamp NULL,
  `created_at` timestamp NULL DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

5. Support Tickets & Root Cause Analysis (RCA)

TICKET-SEC-1201 • Privilege escalation attempt when updating user profile
Security / RBAC

Symptom: A clinic admin attempted to modify their own role to super_admin via intercepted HTTP POST.

Root Cause: UserController::update accepted $request->all() without filtering fillable fields.

Resolution Runbook: In UserController.php, strictly guard role assignment: if ($request->has('role') && Auth::user()->role !== 'super_admin') abort(403);.
