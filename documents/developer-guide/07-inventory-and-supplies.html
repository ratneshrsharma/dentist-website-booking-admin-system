2. Reorder Level Alarms & Thresholds

When current quantity ≤ reorder level, the system triggers:

  • A red badge increment on the top navbar notification bell.
  • An alert pill on the dashboard "Low Stock Warnings" card.
  • An automated purchase order draft populated with the item's default supplier details.

3. Stock Movement Ledger (Audit Trail)

// StockMovementType Enum
enum StockMovementType: string {
    case INBOUND_PURCHASE = 'inbound_purchase';
    case OUTBOUND_PROCEDURE = 'outbound_procedure'; // Decremented upon procedure billing
    case CLINIC_TRANSFER = 'clinic_transfer';       // Moved between branches
    case EXPIRATION_WASTE = 'expiration_waste';     // Material disposed post-expiry
}

4. Database Schema (inventory_items & clinic_stocks)

CREATE TABLE `inventory_items` (
  `id` bigint unsigned NOT NULL AUTO_INCREMENT PRIMARY KEY,
  `sku` varchar(50) NOT NULL UNIQUE,
  `name` varchar(255) NOT NULL,
  `category` varchar(100) NOT NULL,
  `unit_of_measure` varchar(50) NOT NULL,
  `reorder_level` int NOT NULL DEFAULT 5,
  `unit_cost` decimal(10,2) NOT NULL,
  `supplier_name` varchar(255) NOT NULL,
  `created_at` timestamp NULL DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

CREATE TABLE `clinic_stocks` (
  `id` bigint unsigned NOT NULL AUTO_INCREMENT PRIMARY KEY,
  `clinic_id` bigint unsigned NOT NULL,
  `inventory_item_id` bigint unsigned NOT NULL,
  `batch_number` varchar(100) NOT NULL,
  `quantity` int NOT NULL DEFAULT 0,
  `expiry_date` date NOT NULL,
  INDEX `idx_stock_lookup` (`clinic_id`, `inventory_item_id`, `expiry_date`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

5. Support Tickets & Root Cause Analysis (RCA)

TICKET-INV-701 • Negative stock quantity allowed during procedure checkout
Business Rule

Symptom: Doctor checks out implant procedure when stock was 0, resulting in quantity = -1.

Root Cause: Lack of unsigned integer or check constraint on clinic_stocks.quantity.

Resolution Runbook: Add MySQL CHECK (quantity >= 0) constraint or validate quantity availability in BillingCalculationService before committing stock decrement.
