2. Calendly Slots Calculation Algorithm

Availability slots are computed via BookingAvailabilityService.php and served by GET /api/v1/availability/slots?date=YYYY-MM-DD:

// Algorithm: Slot Generation with Operatory Concurrency Check
$morningIntervals = ['09:00', '09:30', '10:00', '10:30', '11:00', '11:30'];
$afternoonIntervals = ['13:30', '14:00', '14:30', '15:00', '15:30', '16:00', '16:30', '17:00'];

foreach ($intervals as $time) {
    // Count existing bookings for this clinic & slot
    $bookedCount = Appointment::where('clinic_id', $clinicId)
        ->whereDate('appointment_date', $date)
        ->where('appointment_time', $time)
        ->whereNotIn('status', ['cancelled', 'no_show'])
        ->count();

    $availableChairs = max(0, $totalChairs - $bookedCount);

    $slots[] = [
        'time' => $time,
        'display' => date('g:i A', strtotime($time)),
        'period' => $hour < 12 ? 'morning' : 'afternoon',
        'available' => $availableChairs > 0,
        'remaining_chairs' => $availableChairs,
    ];
}

5. Support Tickets & Root Cause Analysis (RCA)

TICKET-SCHED-301 • Double booking occurs when two patients book the same slot simultaneously
Race Condition

Symptom: Two patients book 10:00 AM slot at Westside Studio where only 1 chair is available.

Root Cause: Lack of database row locking during the slot validation & insertion window.

Resolution Runbook:

  1. In CreateAppointmentAction.php, wrap booking inside a database transaction with pessimistic locking: 
    DB::transaction(function () use ($data) {
    $existing = Appointment::where('clinic_id', $data['clinic_id'])
        ->where('appointment_date', $data['date'])
        ->where('appointment_time', $data['time'])
        ->lockForUpdate()
        ->count();
    if ($existing >= $totalChairs) {
        throw new SlotUnavailableException("Slot just filled.");
    }
    return Appointment::create($data);
});
TICKET-SCHED-302 • WhatsApp button does not open on desktop browsers
URL Format

Symptom: Clicking WhatsApp icon on Windows chrome opens an invalid URL protocol error.

Root Cause: Using whatsapp://send protocol instead of the universal web fallback https://wa.me/....

Resolution Runbook: Ensure all links use https://wa.me/{phone}?text={encoded} format which automatically handles desktop WhatsApp Web and mobile native app redirection.
