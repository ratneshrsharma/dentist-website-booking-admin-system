2. Standalone Public Invoice Architecture

Patients can view and print their official clinical tax receipt without logging in by visiting the unique receipt URL:
https://demo.ratneshsharma.com/advanced-dental-clinic/billing/INV-2026-0891

Apache Routing via `.htaccess`:

Rule 4 in root .htaccess routes invoice requests directly to PHP:

# Route Billing Invoices & AdminLTE Blade Admin requests to Laravel Public Index
RewriteRule ^(billing|admin)(/.*)?$ backend/public/index.php [L,QSA]

# Exclude billing from Next.js fallback rule
RewriteCond %{REQUEST_URI} !^.*(api|admin|billing|backend|storage)
RewriteRule ^(.*)$ index.html [L]

Invoice Handler in `StandaloneRunner.php`:

public static function handlePublicInvoice(string $invoiceId): void

}

5. Support Tickets & Root Cause Analysis (RCA)

TICKET-BILL-801 • Invoice URL /billing/INV-2026-0891 returns 404 or falls back to Homepage
Resolved in v2.4

Symptom: Patient clicks WhatsApp receipt link, but browser loads Next.js homepage or 404.

Root Cause: In root .htaccess, rule 4 only matched ^admin; billing was intercepted by Rule 9 (Next.js fallback) because billing was not excluded.

Resolution Runbook:

  1. In .htaccess, update Rule 4 to: RewriteRule ^(billing|admin)(/.*)?$ backend/public/index.php [L,QSA].
  2. Update Rule 9 exclusion: RewriteCond %{REQUEST_URI} !^.*(api|admin|billing|backend|storage).
  3. Register route in StandaloneRunner.php line 45: preg_match('#^/(?:admin/)?billing/([A-Za-z0-9\-_]+)$#i', $uri, $matches).
