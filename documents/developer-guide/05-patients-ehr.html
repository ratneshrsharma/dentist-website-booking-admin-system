2. Medical Record Number & Allergy Flags

Every registered patient is assigned an immutable alphanumeric identifier formatted as MRN-YYYY-NNNN (e.g. MRN-2026-0849). The EHR table displays high-visibility pill alerts for critical clinical conditions:

  • Penicillin Allergy - Flags cross-sensitivity to amoxicillin / augmentin.
  • Type 2 Diabetes - Alerts clinician to delayed periodontal healing.
  • Latex Sensitivity - Mandates nitrile gloves in operatory.
  • Hypertension - Restricts epinephrine concentration in local anesthetic.

3. Search & Indexing Engine

The patient search input performs full-text matching across first_name, last_name, email, phone, and medical_record_number using debounced input (300ms) to ensure instantaneous results even with 50,000+ patient records.

4. Database Schema (patient_profiles)

CREATE TABLE `patient_profiles` (
  `id` bigint unsigned NOT NULL AUTO_INCREMENT PRIMARY KEY,
  `user_id` bigint unsigned NULL,
  `medical_record_number` varchar(50) NOT NULL UNIQUE,
  `first_name` varchar(100) NOT NULL,
  `last_name` varchar(100) NOT NULL,
  `email` varchar(255) NOT NULL,
  `phone` varchar(50) NOT NULL,
  `date_of_birth` date NOT NULL,
  `gender` enum('male','female','other') NOT NULL,
  `allergies` json NULL,
  `medical_alerts` json NULL,
  `emergency_contact_name` varchar(255) NULL,
  `emergency_contact_phone` varchar(50) NULL,
  `created_at` timestamp NULL DEFAULT CURRENT_TIMESTAMP,
  INDEX `idx_patient_search` (`last_name`, `phone`, `medical_record_number`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

5. Support Tickets & Root Cause Analysis (RCA)

TICKET-EHR-501 • Duplicate MRN collision error when creating walk-in patient
Unique Key

Symptom: Front desk receives SQL Duplicate entry for key 'medical_record_number' when registering a new patient.

Root Cause: Two receptionists submitted registration forms at the exact same millisecond causing random number generator collision.

Resolution Runbook: Use an auto-incrementing database sequence or UUID v4 prefix: MRN-2026-' . str_pad($seq, 6, '0', STR_PAD_LEFT) to ensure collision-free generation.
