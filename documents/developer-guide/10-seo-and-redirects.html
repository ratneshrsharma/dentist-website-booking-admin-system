2. Yoast-Style Meta Tags & Social Previews

Every page configured in the CMS can have custom SEO tags served dynamically via GET /api/v1/seo?slug={page_slug}:

  • Page Title: Max 60 characters with live character counter.
  • Meta Description: Max 155 characters with Google snippet preview.
  • OpenGraph Tags: og:title, og:description, og:image, og:url.
  • X (Twitter) Card: summary_large_image with high-resolution thumbnail support.
  • Custom Code Injection: Custom CSS/JS before </head> or before </body> (Google Tag Manager, Meta Pixel).

4. 301 / 302 Redirection Engine

Redirects are stored in MySQL seo_redirects table and matched during Apache request resolution or by StandaloneRunner.php:

CREATE TABLE `seo_redirects` (
  `id` bigint unsigned NOT NULL AUTO_INCREMENT PRIMARY KEY,
  `source_path` varchar(255) NOT NULL UNIQUE,
  `target_url` varchar(255) NOT NULL,
  `status_code` smallint NOT NULL DEFAULT 301,
  `hit_count` bigint unsigned NOT NULL DEFAULT 0,
  `last_accessed_at` timestamp NULL,
  `created_at` timestamp NULL DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

5. Support Tickets & Root Cause Analysis (RCA)

TICKET-SEO-1001 • Circular 301 Redirect Loop caused by trailing slash discrepancies
Loop / 301

Symptom: Browser reports ERR_TOO_MANY_REDIRECTS when visiting /treatments/dental-implants/.

Root Cause: Next.js export has trailingSlash: true, but admin redirect was created as /treatments/dental-implants → /treatments/dental-implants/ which collided with Apache rules.

Resolution Runbook: In StandaloneRunner.php, normalize source and target paths using rtrim($path, '/') before matching.
